# LLM 对话标注体系维度清单

本文档汇总了LLM对话数据标注的评估维度，分为“现有核心维度”和“建议新增维度”两部分，构成一个全面的标注体系蓝图。

## 现有核心维度

这是根据最初提供的专业设计整理的核心标注维度，覆盖了质量、安全与RAG评估的基础。

| 大类 | 维度名称 | 标注方式 | 核心价值 |
| :--- | :--- | :--- | :--- |
| **整体对话评估** | **对话意图分类** (`intentCategory`) | 单选标签 (信息查询/指令遵循/内容创作/闲聊) | 理解用户核心需求，对不同类型的任务进行针对性评估与优化。 |
| | **对话完整性** (`completeness`) | 单选标签 (完整/不完整) | 判断模型是否彻底解决了用户的问题，评估任务完成度。 |
| | **整体满意度** (`overallSatisfaction`) | 1-5星评分 | 提供一个总体的、直观的对话质量反馈，是衡量综合表现的关键指标。 |
| | **一般备注** (`generalNotes`) | 文本输入框 | 捕获评级和标签无法覆盖的、开放性的、任何值得记录的反馈。 |
| **LLM 回复质量** | **相关性** (`relevance`) | 单选标签 (强相关/相关/弱相关/不相关) | 评估模型是否跑题，是否准确理解并回应了用户的提问。 |
| | **流畅性** (`fluency`) | 单选标签 (非常流畅/流畅/不流畅) | 衡量模型语言组织能力，是否自然、合乎语法、无拼接痕迹。 |
| | **幻觉/事实错误** (`hasHallucination`) | 布尔值 (是/否) + 文本描述 | 识别并记录模型“一本正经地胡说八道”的情况，是模型可靠性的关键。 |
| | **内容合规性** (`compliance`) | 单选标签 (合规/有风险/违规/无法判断) | 评估内容安全红线，确保模型输出符合法规和道德规范。 |
| | **违规类型与详情** (`violationTypes`) | 多选框 + 文本描述 | 当存在不合规内容时，对其进行分类和详述，便于追溯和修复。 |
| | **改进建议** (`improvementSuggestion`) | 文本输入框 | 针对单轮回复，给出具体的、可操作的优化建议。 |
| **RAG 召回评估** | **知识与问题的相关性** (`relevanceToQuestion`) | 单选标签 (强相关/相关/弱相关/不相关) | 评估检索系统（Retriever）的能力，判断召回的知识是否对路。 |
| | **知识对回复的支持度** (`supportToResponse`) | 单选标签 (完全支持/部分支持/不支持) | 检验生成器（Generator）是否忠于召回的知识，是衡量RAG幻觉的核心。 |
| | **知识的错误/过时性** (`hasError`) | 布尔值 (是/否) + 文本描述 | 判断知识库本身是否存在问题，反哺知识库的维护和更新。 |
| | **知识的冗余性** (`isRedundant`) | 布尔值 (是/否) | 评估召回的知识是否存在不必要的重复，影响生成回复的简洁性。 |

## 新增维度 (拓展评估)

这是建议在现有基础上拓展的全新标注维度，侧重于评估用户体验、深度认知能力与进行对比优化。

| 大类 | 维度名称 | 标注方式 | 核心价值 |
| :--- | :--- | :--- | :--- |
| **用户体验** | **语气与风格** (Tone & Style) | 单选标签 (友好且热情/专业且严谨/中立客观/富有同理心/风趣幽默/机械刻板/冷漠生硬/过于随意/说教/居高临下) | 塑造品牌形象，提升亲和力 |
| | **参与度和主动性** (Engagement & Proactiveness) | 多选框 (主动澄清与追问/提供额外相关信息/预判用户潜在需求/引导对话方向/表达共情与认可/总结归纳要点/无以上行为) | 培养更智能的对话伙伴 |
| | **格式与可读性** (Formatting & Readability) | 是/否 或 1-5分评级 | 优化信息呈现，提升阅读体验 |
| **深度认知** | **指令遵循精细度** (Instruction Following Granularity) | 清单检查 (Checklist) | 训练模型遵循复杂、带约束的指令 |
| | **逻辑与推理** (Logic & Reasoning) | 评级标签 (逻辑清晰/逻辑基本正确，但步骤可优化/存在部分逻辑跳跃或不严谨/存在明显逻辑谬误/无逻辑可言/无法判断) | 提升解决复杂问题的核心智能 |
| | **创造力评估** (Creativity Assessment) | 1-5分制打分 + 标签 | 优化内容创作类任务的能力 |
| **对比与优化** | **模型对比标注** (A/B Test Annotation) | A/B二选一 + 理由 | 模型迭代效果的黄金标准 |
| | **优化重写** (Optimal Rewrite) | 标注员直接撰写“完美回复” | 产生最高质量的SFT数据 |
